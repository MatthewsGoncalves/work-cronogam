# Biblioteca pessoal de currículos

Esta pasta é privada por padrão e seu conteúdo não é enviado ao Git.

Antes de usar o projeto, copie os arquivos de `modelos/` para esta pasta:

```bash
cp modelos/curriculo-pt.exemplo.md base/curriculo-pt.md
cp modelos/resume-en.example.md base/resume-en.md
```

Depois:

1. Substitua todos os campos entre colchetes pelos seus dados reais.
2. Acrescente experiências, formação, competências e resultados verificáveis.
3. Se quiser, adicione `base/Profile.pdf`, exportado do LinkedIn.
4. Nunca coloque no currículo adaptado algo que não esteja documentado nesta base.

Arquivos esperados:

- `curriculo-pt.md` — fonte de verdade em português.
- `resume-en.md` — fonte de verdade em inglês.
- `Profile.pdf` — fonte complementar opcional.
